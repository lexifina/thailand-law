มาตรา ๙๑ คนต่างด้าวที่ได้รับอนุญาตให้ใช้ที่ดินเพื่อกิจการใด ถ้าได้รับอนุญาตใหม่ ให้ใช้ที่ดินนั้นเพื่อกิจการอื่นซึ่งจำนวนที่ดินที่ได้รับอนุญาตนี้ลดลง ให้จำหน่ายที่ดินส่วนที่เกินนั้นภายในเวลาที่อธิบดีกำหนด ซึ่งไม่น้อยกว่าหนึ่งร้อยแปดสิบวัน แต่ไม่ให้เกินหนึ่งปี ถ้าพ้นกำหนดเวลาดังกล่าว ให้อธิบดีมีอำนาจจำหน่ายที่ดินนั้น
