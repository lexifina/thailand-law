มาตรา ๓๙ ภายใต้บังคับมาตรา ๓๖ บุคคลใดได้มาซึ่งสิทธิในที่ดินโดยบทบัญญัติมาตรา ๗๒๙ แห่งประมวลกฎหมายแพ่งและพาณิชย์เมื่อประมวลกฎหมายนี้ได้ใช้บังคับแล้วและที่ดินที่ได้มานั้นเมื่อรวมกับที่ดินที่บุคคลนั้นมีอยู่เดิมเกินจำนวนที่บัญญัติไว้ในมาตรา ๓๔ ให้จำหน่ายที่ดินส่วนที่เกินนั้นภายในเจ็ดปี นับแต่วันที่ได้มาซึ่งสิทธิในที่ดินนั้น ถ้าบุคคลนั้นไม่สามารถจำหน่ายที่ดินส่วนที่เกินนั้นได้ ให้อธิบดีมีอำนาจจำหน่ายที่ดินส่วนที่เกินนั้นแก่บุคคลอื่นได้
