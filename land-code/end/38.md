พระราชบัญญัติแก้ไขเพิ่มเติมประมวลกฎหมายที่ดิน (ฉบับที่ ๑๕) พ.ศ. ๒๕๖๒[^1]

มาตรา ๒ พระราชบัญญัตินี้ให้ใช้บังคับเมื่อพ้นกำหนดหนึ่งร้อยแปดสิบวันนับแต่วันประกาศในราชกิจจานุเบกษาเป็นต้นไป

มาตรา ๕ ในระหว่างที่ยังไม่เริ่มใช้บัญชีราคาประเมินทรัพย์สินตามกฎหมายว่าด้วยการประเมินราคาทรัพย์สินเพื่อประโยชน์แห่งรัฐ ให้พนักงานเจ้าหน้าที่เรียกเก็บค่าธรรมเนียมจดทะเบียนสิทธิและนิติกรรมโดยคำนวณตามราคาประเมินทุนทรัพย์ของอสังหาริมทรัพย์เพื่อเรียกเก็บค่าธรรมเนียมจดทะเบียนสิทธิและนิติกรรม ซึ่งใช้อยู่ในวันก่อนวันที่พระราชบัญญัตินี้ใช้บังคับไปพลางก่อน จนกว่าจะมีบัญชีราคาประเมินทรัพย์สินตามกฎหมายว่าด้วยการประเมินราคาทรัพย์สินเพื่อประโยชน์แห่งรัฐใช้บังคับ

มาตรา ๖ ให้รัฐมนตรีว่าการกระทรวงมหาดไทยรักษาการตามพระราชบัญญัตินี้

[^1]: ราชกิจจานุเบกษา เล่ม ๑๓๖/ตอนที่ ๖๘ ก/หน้า ๓๒/๒๕ พฤษภาคม ๒๕๖๒
