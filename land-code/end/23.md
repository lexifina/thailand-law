หมายเหตุ :- เหตุผลในการประกาศใช้พระราชบัญญัติฉบับนี้ คือ โดยที่เป็นการสมควรแก้ไขเพิ่มเติมผู้มีอำนาจหน้าที่ในการสั่งเพิกถอนหรือแก้ไขโฉนดที่ดินหรือหนังสือรับรองการทำประโยชน์โดยให้อธิบดีกรมที่ดินหรือรองอธิบดีซึ่งอธิบดีมอบหมายเป็นผู้มีอำนาจหน้าที่ในการสั่งเพิกถอนหรือแก้ไขโฉนดที่ดินหรือหนังสือรับรองการทำประโยชน์แต่เพียงฝ่ายเดียวเพื่อให้การดำเนินการสั่งเพิกถอนหรือแก้ไข ในกรณีดังกล่าวเป็นไปด้วยความรวดเร็ว นอกจากนี้ เห็นสมควรแก้ไขบทบัญญัติเกี่ยวกับการจดทะเบียนเกี่ยวกับอสังหาริมทรัพย์ซึ่งได้มาโดยทางมรดก การอายัดที่ดิน การเรียกเก็บค่าธรรมเนียมจดทะเบียนสิทธิและนิติกรรม ตลอดจนบัญชีอัตราค่าธรรมเนียมและค่าใช้จ่ายท้ายประมวลกฎหมายที่ดินให้เหมาะสมยิ่งขึ้น จึงจำเป็นต้องตราพระราชบัญญัตินี้
