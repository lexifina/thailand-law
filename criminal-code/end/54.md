พระราชบัญญัติแก้ไขเพิ่มเติมประมวลกฎหมายอาญา (ฉบับที่ ๒๕) พ.ศ. ๒๕๕๙[^1]

มาตรา ๒ พระราชบัญญัตินี้ให้ใช้บังคับตั้งแต่วันถัดจากวันประกาศในราชกิจจานุเบกษาเป็นต้นไป

มาตรา ๑๐ บทบัญญัติมาตรา ๓๐ แห่งประมวลกฎหมายอาญา ซึ่งแก้ไขเพิ่มเติมโดยพระราชบัญญัตินี้ ให้ใช้บังคับแก่ผู้ที่ถูกกักขังแทนค่าปรับอยู่ในวันที่พระราชบัญญัตินี้ใช้บังคับด้วย และเมื่อคำนวณระยะเวลาการกักขังแทนค่าปรับตามอัตราใหม่แล้ว หากปรากฏว่าผู้นั้นถูกกักขังมาจนครบหรือเกินระยะเวลาที่คำนวณได้ดังกล่าว หรือในกรณีที่ศาลพิพากษาให้ปรับไม่ถึงสองแสนบาทและผู้นั้นถูกกักขังมาเกินกำหนดหนึ่งปีแล้ว ให้ปล่อยตัวไปทันที

มาตรา ๑๑ ให้ประธานศาลฎีกาและรัฐมนตรีว่าการกระทรวงยุติธรรมรักษาการตามพระราชบัญญัตินี้

[^1]: ราชกิจจานุเบกษา เล่ม ๑๓๓/ตอนที่ ๓๑ ก/หน้า ๑/๗ เมษายน ๒๕๕๙
