พระราชบัญญัติแก้ไขเพิ่มเติมประมวลกฎหมายอาญา (ฉบับที่ ๑๕) พ.ศ. ๒๕๔๕[^1]

มาตรา ๒ พระราชบัญญัตินี้ให้ใช้บังคับตั้งแต่วันถัดจากวันประกาศในราชกิจจานุเบกษาเป็นต้นไป เว้นแต่มาตรา ๓ ให้ใช้บังคับเมื่อพ้นกำหนดสามปีนับแต่วันถัดจากวันประกาศในราชกิจจานุเบกษาเป็นต้นไป

[^1]: ราชกิจจานุเบกษา เล่ม ๑๒๐/ตอนที่ ๔ ก/หน้า ๑/๘ มกราคม ๒๕๔๖
