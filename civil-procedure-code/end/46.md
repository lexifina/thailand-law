หมายเหตุ :- เหตุผลในการประกาศใช้พระราชบัญญัติฉบับนี้ คือ เนื่องจากบทบัญญัติของประมวลกฎหมายวิธีพิจารณาความแพ่งในส่วนที่เกี่ยวกับค่าฤชาธรรมเนียมยังมีความไม่เหมาะสมหลายประการ และไม่ได้แยกค่าฤชาธรรมเนียมในการพิจารณาคดีออกจากค่าฤชาธรรมเนียมในการบังคับคดี รวมทั้งอัตราค่าฤชาธรรมเนียมในตารางท้ายประมวลกฎหมายวิธีพิจารณาความแพ่งใช้บังคับมาเป็นเวลานานไม่เหมาะสมกับสถานการณ์ปัจจุบัน สมควรแก้ไขเพิ่มเติมบทบัญญัติเรื่องค่าฤชาธรรมเนียมและตารางท้ายประมวลกฎหมายวิธีพิจารณาความแพ่งให้มีความเหมาะสมยิ่งขึ้น นอกจากนี้ สมควรกำหนดให้หลักเกณฑ์และวิธีการในการไกล่เกลี่ยของศาล การแต่งตั้งผู้ประนีประนอม รวมทั้งอำนาจหน้าที่ของผู้ประนีประนอม เป็นไปตามที่กำหนดในข้อกำหนดของประธานศาลฎีกา และแก้ไขเพิ่มเติมหลักเกณฑ์การขอเลื่อนการนั่งพิจารณาและการพิจารณาคำขอเลื่อนการนั่งพิจารณาให้เคร่งครัดยิ่งขึ้น ตลอดจนแก้ไขเพิ่มเติมการดำเนินกระบวนพิจารณาคดีมโนสาเร่และคดีไม่มีข้อยุ่งยากให้ชัดเจนขึ้น จึงจำเป็นต้องตราพระราชบัญญัตินี้
