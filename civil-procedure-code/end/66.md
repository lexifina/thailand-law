หมายเหตุ :- เหตุผลในการประกาศใช้พระราชบัญญัติฉบับนี้ คือ โดยที่ตาราง ๕ ค่าธรรมเนียมเจ้าพนักงานบังคับคดี ท้ายประมวลกฎหมายวิธีพิจารณาความแพ่งที่ใช้บังคับอยู่ได้กำหนดค่าธรรมเนียมเจ้าพนักงานบังคับคดีไม่สอดคล้องกับสภาพการณ์ทางเศรษฐกิจและสังคมในปัจจุบัน สมควรยกเลิกหรือลดค่าธรรมเนียมเจ้าพนักงานบังคับคดีเพื่อแบ่งเบาภาระของประชาชนในการดำเนินคดี และเพื่อเป็นการส่งเสริมและสนับสนุนให้มีการเจรจาไกล่เกลี่ยหนี้ระหว่างเจ้าหนี้และลูกหนี้ให้มากขึ้นอันเป็นการช่วยลดปริมาณการบังคับคดี สมควรแก้ไขเพิ่มเติมค่าธรรมเนียมเจ้าพนักงานบังคับคดีให้มีความเหมาะสมยิ่งขึ้น จึงจำเป็นต้องตราพระราชบัญญัตินี้
