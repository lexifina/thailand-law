มาตรา ๒๐๒ ผู้อุทธรณ์มีอำนาจยื่นคำร้องขอถอนอุทธรณ์ต่อศาลชั้นต้นก่อนส่งสำนวนไปศาลอุทธรณ์ ในกรณีเช่นนี้ศาลชั้นต้นสั่งอนุญาตได้ เมื่อส่งสำนวนไปแล้ว ให้ยื่นต่อศาลอุทธรณ์หรือต่อศาลชั้นต้นเพื่อส่งไปยังศาลอุทธรณ์เพื่อสั่ง ทั้งนี้ ต้องก่อนอ่านคำพิพากษาศาลอุทธรณ์

เมื่อถอนไปแล้ว ถ้าคู่ความอีกฝ่ายหนึ่งมิได้อุทธรณ์ คำพิพากษาหรือคำสั่งของศาลชั้นต้นย่อมเด็ดขาดเฉพาะผู้ถอน ถ้าอีกฝ่ายหนึ่งอุทธรณ์ จะเด็ดขาดต่อเมื่อคดีถึงที่สุดโดยไม่มีการแก้คำพิพากษาหรือคำสั่งศาลชั้นต้น
