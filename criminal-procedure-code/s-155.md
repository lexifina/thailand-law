มาตรา ๑๕๕ ให้นำบทบัญญัติในประมวลกฎหมายนี้อันว่าด้วยการสอบสวนมาใช้แก่การชันสูตรพลิกศพโดยอนุโลม

ให้นำบทบัญญัติในมาตรา ๑๗๒ ตรี มาใช้บังคับโดยอนุโลมแก่การไต่สวนของศาลตามมาตรา ๑๕๐ ในคดีที่พยานเป็นเด็กอายุไม่เกินสิบแปดปี[^1]

[^1]: มาตรา ๑๕๕ วรรคสอง เพิ่มโดยพระราชบัญญัติแก้ไขเพิ่มเติมประมวลกฎหมายวิธีพิจารณาความอาญา (ฉบับที่ ๒๐ ) พ.ศ. ๒๕๔๒
