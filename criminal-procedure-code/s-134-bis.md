มาตรา ๑๓๔ ทวิ[^1] ในคดีที่ผู้ต้องหามีอายุไม่เกินสิบแปดปีในวันที่พนักงานสอบสวนแจ้งข้อหา ก่อนเริ่มถามคำให้การให้พนักงานสอบสวนถามผู้ต้องหาว่ามีทนายความหรือไม่ ถ้าไม่มีให้รัฐจัดหาทนายความให้

การจัดหาทนายความตามวรรคหนึ่ง ให้พนักงานสอบสวนปฏิบัติตามหลักเกณฑ์ วิธีการ และเงื่อนไขที่กำหนดในกฎกระทรวง และให้ทนายความที่รัฐจัดหาให้ได้รับเงินรางวัลและค่าใช้จ่ายตามระเบียบที่กระทรวงยุติธรรมกำหนดโดยได้รับความเห็นชอบจากกระทรวงการคลัง

[^1]: มาตรา ๑๓๔ ทวิ เพิ่มโดยพระราชบัญญัติแก้ไขเพิ่มเติมประมวลกฎหมายวิธีพิจารณาความอาญา (ฉบับที่ ๒๐ ) พ.ศ. ๒๕๔๒
