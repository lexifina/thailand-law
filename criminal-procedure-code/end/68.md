พระราชบัญญัติแก้ไขเพิ่มเติมประมวลกฎหมายวิธีพิจารณาความอาญา (ฉบับที่ ๓๒) พ.ศ. ๒๕๕๙[^1]

มาตรา ๒ พระราชบัญญัตินี้ให้ใช้บังคับตั้งแต่วันถัดจากวันประกาศในราชกิจจานุเบกษาเป็นต้นไป

มาตรา ๕ บรรดาคดีที่ได้ยื่นอุทธรณ์หรือฎีกาไว้ก่อนวันที่พระราชบัญญัตินี้ใช้บังคับให้บังคับตามกฎหมายซึ่งใช้อยู่ก่อนวันที่พระราชบัญญัตินี้ใช้บังคับ

มาตรา ๖ ให้ประธานศาลฎีการักษาการตามพระราชบัญญัตินี้

[^1]: ราชกิจจานุเบกษา เล่ม ๑๓๓/ตอนที่ ๑๐๔ ก/หน้า ๓๐/๑๑ ธันวาคม ๒๕๕๙
