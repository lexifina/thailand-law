มาตรา ๑๓๓ ตรี[^1] ในกรณีที่พนักงานสอบสวนมีความจำเป็นต้องจัดให้เด็กอายุไม่เกินสิบแปดปีในฐานะเป็นผู้เสียหายหรือพยานชี้ตัวผู้ต้องหา ให้พนักงานสอบสวนจัดให้มีการชี้ตัวผู้ต้องหาในสถานที่ที่เหมาะสมและสามารถจะป้องกันมิให้ผู้ต้องหาเห็นตัวผู้เสียหายหรือพยาน การชี้ตัวผู้ต้องหาดังกล่าวให้มีนักจิตวิทยาหรือนักสังคมสงเคราะห์ บุคคลที่เด็กร้องขอ และพนักงานอัยการร่วมอยู่ด้วย และให้นำบทบัญญัติในมาตรา ๑๓๓ ทวิ วรรคห้า มาใช้บังคับโดยอนุโลม

[^1]: มาตรา ๑๓๓ ตรี เพิ่มโดยพระราชบัญญัติแก้ไขเพิ่มเติมประมวลกฎหมายวิธีพิจารณาความอาญา (ฉบับที่ ๒๐ ) พ.ศ. ๒๕๔๒
